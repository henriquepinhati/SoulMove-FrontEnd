# SoulMove — Frontend
Projeto acadêmico — SoulMove (Challenge FIAP + SoulUp)
## Descrição
Site institucional e demonstrativo que permite simular a conversão de pontos SoulUp em vouchers de transporte, visualizar CO2 evitado e acompanhar um dashboard fictício.
## Objetivo
Implementar um MVP front-end usando apenas HTML5, CSS3 e JavaScript puro conforme especificação do desafio.
## Tecnologias
- HTML5
- CSS3
- JavaScript
## Estrutura de pastas
```
soulmove-frontend/
├── index.html
├── sobre.html
├── integrantes.html
├── faq.html
├── contato.html
├── simulador.html
├── dashboard.html
├── README.md
├── css/
│   └── style.css
├── js/
│   └── script.js
└── assets/
   └── imagens/
```
## Funcionalidades
- Menu responsivo (hambúrguer) em todas as páginas
- Accordion em FAQ
- Validação do formulário de contato com feedback
- Simulador de viagem com cálculo de CO2 evitado e verificação de pontos
- Dashboard com atualização aleatória
## Como executar
1. Abra a pasta `soulmove-frontend` no seu servidor estático ou simplesmente abra `index.html` no navegador.
